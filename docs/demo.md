# Demo: from a YouTube link to a mastered sketch

Listen: [`demo/claude-future-bass-sketch.mp3`](../demo/claude-future-bass-sketch.mp3) ·
Project: [`demo/claude-future-bass-sketch.flp`](../demo/claude-future-bass-sketch.flp) (FL Studio 2025, stock
content only) · Notes as data: [`demo/song.json`](../demo/song.json), generated by
[`skills/fl-studio/assets/examples/future_bass_sketch.py`](../skills/fl-studio/assets/examples/future_bass_sketch.py).

The prompt was roughly: *"Use this song as a reference and see how far you can take it:
ILLENIUM - Needed You (feat. Dia Frampton). There are vocals, don't stress those."*
Everything below was done by Claude through the MCP tools. The reference audio is not in this repo.

## 1. Reference analysis (`fl_reference_analyze`, ~30 s)

| | Result |
|---|---|
| Tempo | 92.3 BPM grid (184.6 double also strong) |
| Key | estimator: "B major"; chords + bass say **E major / C# minor** |
| Harmony | looping **A – B – C#m – (B or E)** = IV – V – vi in E |
| Drop rhythm | syncopated hits on 16th-steps ~1, 7, 13 (3-3-2 future-bass stabs), half-time drums |
| Energy map | intro → hook → verse → long build → drop (bars ~54–63) → breakdown → build → final drop → outro |

## 2. Sounds (`fl_clone_channel`, `fl_flex_select_pack`, `fl_flex_load_preset`)

Five clones of the template's FLEX channel, each routed to its own mixer insert:

| Part | FLEX pack | Preset |
|---|---|---|
| Sub bass | Olbaid Bass Utopia | Deep Sense |
| Piano | Essential Pianos | Steinway D |
| Supersaw chords | Black Octopus Pandora | Supersaw Nation |
| Pluck lead | Mobile Synth Pluck | Synpluck Glass |
| Pad | Essential Strings | All Strings Slow |
| Growl accents | Olbaid Bass Utopia | Growling Machine |

Drums: the Default template's 808 Kick / Clap / HiHat / Snare.

## 3. Composition (original, 48 bars at 92 BPM, ~1,470 notes)

| Bars | Section | What plays |
|---|---|---|
| 1–8 | Intro | piano chords C#m – A – E – B (vi IV I V), strings |
| 9–16 | Verse | piano arpeggios, pluck melody, sub, light kick/clap/hats |
| 17–24 | Build | swelling supersaws over A – B – G#m – C#m, accelerating snare roll, half-bar gap |
| 25–40 | Drop | 3-3-2 supersaw stabs, pluck hook (octave up on the repeat), sub + growl answers, full drums |
| 41–48 | Outro | piano + strings, held C#m |

The progressions and melody are new; only key, tempo, energy arc and rhythmic feel follow the reference.

## 4. Mix and master, measured against the reference drop

`fl_render_wav` → `fl_compare_to_reference`, iterating with fader trims, stereo separation and the
Master's Emphasizer input gain:

| Version | LUFS | Width gap (side/mid) | Brightness gap |
|---|---|---|---|
| v1 (unmastered) | −27.5 | −6.6 dB | −202 Hz |
| v2 (Emphasizer +16.8 dB, widen) | −9.5 | −2.6 dB | −25 Hz |
| v3 (more low end) | −9.3 | −4.0 dB | −318 Hz |
| v4 (rebalanced) / final | **−8.1** | **−1.9 dB** | **−3 to −51 Hz** |

The reference measured −2.4 LUFS (extremely limited); the sketch deliberately stops at a sane
loudness. The remaining gap (bass −3 dB, low-mids +2 dB) needs an EQ plugin, which FL's API can't add.

## What a human would still do

Load an EQ and a sidechain compressor, add vocals or a topline, arrange sections as separate
patterns in the playlist, and above all listen and adjust taste.
